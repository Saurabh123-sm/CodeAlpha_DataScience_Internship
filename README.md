# CodeAlpha Data Science Internship

| Folder | Task |
|---|---|
| `Task1_Iris_Classification` | Task 1: Iris Flower Classification (SVM, 96.7% test accuracy) |
| `Task4_Sales_Prediction` | Task 4: Sales Prediction using Python (Gradient Boosting, R2 0.983) |

## Run in VS Code
1. Unzip and open this folder in VS Code (File > Open Folder).
2. Open the terminal (Ctrl+`) and install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Run each project (right-click the file > Run Python File, or):
   ```
   python Task1_Iris_Classification/iris_classification.py
   python Task4_Sales_Prediction/sales_prediction.py
   ```
Plots and result tables are saved inside each task folder. Each task folder has its own README with approach, results and insights.
